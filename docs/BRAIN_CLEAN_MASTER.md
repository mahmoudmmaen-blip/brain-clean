\# Brain Clean Master Reference



\## Global Rule



Read this file first before working on Brain Clean.



Work only inside:



brain\_clean\_mobile/



Do not modify root lib/.



\## Product North Star



The North Star is the Daily Program.



The user opens Brain Clean to complete today’s guided recovery journey.



If a feature does not clearly support the Daily Program, it should not be added.



\## Daily Program Rhythm



Prepare → Focus → Reflect → Complete → Rest



Completion means commitment, not perfection.
