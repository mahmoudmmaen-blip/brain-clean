# Brain Clean 🧠

تطبيق Flutter عربي لمساعدة الشباب العربي على التعافي من إدمان الشاشات وإعادة بناء التركيز.

## Features
- BCI Score (Brain Clarity Index): 60% Assessment + 40% Adherence
- 30-Day Recovery Challenge
- Pomodoro & Focus Tools
- AI Coach: Safa (Claude via secure Edge Function)
- Cognitive Tests (Visual + Memory)
- 6 Color Themes (2 free, 4 Pro)
- XP Gamification (10 Arabic levels, 0–10,000 XP)
- Biometric Lock + Root Detection
- Fully Arabic RTL, Cairo Font

## Tech Stack
Flutter • Riverpod • Hive (AES-256) • Supabase • RevenueCat • GoRouter • Freezed

## Package
com.brainclean.mobile

## Run
```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run -d <device_id>
```
