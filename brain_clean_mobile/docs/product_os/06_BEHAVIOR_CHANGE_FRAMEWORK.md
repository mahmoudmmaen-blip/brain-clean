# 06 — Behavior Change Framework

**Purpose:** Map science → Daily Program without addiction mechanics.

---

## Models we use (pragmatically)

### COM-B
Behavior needs **Capability**, **Opportunity**, **Motivation**.  
Design: reduce capability barriers (fog), increase opportunity (clear next step), support motivation without shame.

### Fogg Behavior Model (B = MAP)
Behavior happens when Motivation, Ability, Prompt converge.  
Prefer raising **Ability** (simpler steps) over hype Motivation.

### Habit loop
Cue → Routine → Reward.  
Reward = quiet completion / Day End pride — not casino dopamine.

### Implementation intentions
“When X, I will Y” — useful for morning start and night close.

### Tiny habits
Start smaller than ego wants (Light Day).

### Self-efficacy
Show progress as completed behaviors, not clinical scores.

### Friction & environment design
Add friction to compulsive phone patterns **only** with ethical, optional tools; never shame.  
Full blockers deferred historically — **OPEN QUESTION** for future.

---

## Ethical rewards

Allowed: checkmarks, calm micro-copy, Day End summary, narrative weekly progress.  
Rejected: infinite variable rewards, public humiliation, punitive score loss as engagement driver.

---

## Streaks & progress

- Prefer **forgiveness** and “return counts.”  
- Avoid “you broke everything” streak deaths.  
- Alternatives: weekly completion count, compassion streak, “days showed up.”

---

## Relapse & missed-day recovery

**PRODUCT DECISION:** Missed days are expected. Return is celebrated.  
Offer Light Day / recovery day.  
Never reset identity to failure.

---

## User value vs addictive engagement

| Valuable | Addictive (reject) |
|----------|-------------------|
| Completing Daily Program | Maximizing session time |
| Leaving app to live | Endless feed / games grind |
| Clear next step | Feature roulette |
| Quiet pride | Spectacle fireworks every tap |
