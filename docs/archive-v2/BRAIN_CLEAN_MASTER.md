# الجزء الأول: 🧭 دستور المنتج (PRODUCT)

هذا هو **الدستور**. أي ميزة أو قرار تصميم يُقاس عليه. لو تعارض أي شيء معه، الدستور هو الفيصل.

## ⭐ النجم الشمالي (North Star)

> **المستخدم يفتح "برنامجي اليومي" ويكمّل رحلة يومه.**

هذا هو **السلوك الوحيد** الذي يحدد نجاح التطبيق. كل ما عداه يخدم هذا السلوك أو لا مكان له.

### القاعدة الحاكمة (أهم سطر في الدستور)

> **إذا لم تخدم الميزة "البرنامج اليومي" أو تحسّن رحلة المستخدم اليومية بشكل واضح — فلا تُضاف.**

## 🎯 الجمهور المستهدف

**نبدأ بـ:** الشاب/الشابة العربي الذي يشعر أن السكرول يأكل يومه ويشتّت تركيزه.
**نتوسّع إلى:** كل من يعاني من فوضى رقمية ويبحث عن هدوء وروتين صحي.

## 💎 قلب التطبيق: البرنامج اليومي (Daily Recovery)

البرنامج اليومي **ليس قائمة مهام** — بل **رحلة اليوم بالكامل**.

> **لو كان لـ Brain Clean ميزة واحدة فقط، لكانت البرنامج اليومي. كل ما عداه موجود ليقوّيه.**

### الإيقاع الثابت (لا يتغيّر أبداً)

```
تهيئة  →  تركيز  →  تأمّل  →  إكمال  →  راحة
Prepare → Focus → Reflect → Complete → Rest
```

**المحتوى يتغيّر — الإيقاع لا يتغيّر.** هذا ما يجعل الرحلة مألوفة ومريحة كل يوم.

### اليوم التكيّفي (Adaptive Day)

البرنامج يتكيّف مع حالة المستخدم، لا العكس:

| نوع اليوم | متى | الطول |
|---|---|---|
| **يوم خفيف** | مرهق / مشغول | خطوات أساسية فقط |
| **يوم متوسط** | الوضع الطبيعي | الرحلة الكاملة |
| **يوم عميق** | نشيط ومتحمّس | + جلسة سكون أطول |
| **يوم تعافي** | بعد انقطاع | لطيف جداً، بلا ضغط |

**الهدف: استمرارية مستدامة — لا أقصى مجهود.**

### تعريف الإكمال

> **الإكمال = التزام، لا كمال.**

البرنامج يكتمل عندما يشارك المستخدم **بوعي** في رحلة يومه — لا بالضرورة عندما ينهي كل نشاط اختياري.

### رحلة اليوم (7 خطوات)

```
🌅 بداية اليوم        → تسجيل بداية + نية اليوم
💧 ماء                → تسجيل سريع
🚶 الحركة             → تسجيل سريع
🧘 سكون               → جلسة هدوء (Wakeful Rest)
😊 المزاج             → تقييم سريع
📝 دفتر اليوم/القلق    → عند الحاجة فقط (اختياري)
🏁 إغلاق اليوم         → إغلاق واعٍ للرحلة
```

### تصميم الشاشة: رحلة هجينة (Hybrid Journey)

القرار النهائي — تجمع مزايا القائمة الكاملة + الخطوة الواحدة + اللوحة المفتوحة:

1. **رسالة صباحية أولاً** (Priming) — تضبط الحالة النفسية قبل أي مهمة. فلسفتها: "الهدف ليس الكمال، بل خطوة في الاتجاه الصحيح". مجموعة رسائل تتبدّل يومياً.
2. **رؤية سريعة لليوم** — التقدم + عدد الخطوات المتبقية + شريط تقدم.
3. **تركيز على خطوة واحدة** — بطاقة كبيرة للخطوة الحالية فقط، وبعد "تم" تتحول تلقائياً للتالية.
4. **مكافأة صغيرة (Micro-reward)** بعد كل خطوة — متنوّعة وبسيطة، بلا مبالغة (✔ رائع / +5 نقاط هدوء).
5. **قائمة كل الخطوات** أسفل الشاشة — يرى الخريطة كاملة، لكن التطبيق يقوده للتالية.

### كيف تخدم الميزات البرنامج اليومي

| الميزة | دورها |
|---|---|
| **سكون** | خطوة أساسية داخل البرنامج |
| **دفتر القلق** | خطوة اختيارية عند الحاجة |
| **صفا** | مساعد يظهر أثناء الرحلة، لا تاب معزول |
| **المؤشرات (BCI/الهدوء)** | **نتيجة** للرحلة — لا صفحات منفصلة |
| **الاختبارات** | نقطة بداية للتخصيص، لا وجهة يومية |
| **الألعاب** | استراحة اختيارية، لا محور |

### حلقة المستخدم اليومية (Engagement Loop)

```
فتح → البرنامج اليومي → إكمال اليوم → التقرير → تحسّن المؤشرات → إنجاز → يرجع غداً
```
المكافأة (تقرير + مؤشرات + إنجاز) تأتي **بعد** الفعل، لا قبله.

### الرحلة الشعورية (Emotional Journey)

كل جلسة يومية يجب أن تمرّ بهذه الحالات الشعورية بالترتيب:

```
حيرة → أمل → تركيز → تقدّم → ثقة → تأمّل → فخر هادئ → إغلاق
```

**لا شاشة يجوز أن تقطع هذا التدفّق.** الناس لا تتذكّر الميزات — تتذكّر **كيف جعلها المنتج تشعر**.

### مبادئ التصميم الشعوري

1. **الهدوء قبل الفعل** — أول مسؤولية للواجهة ليست الإنتاجية، بل تنظيم المشاعر.
2. **تقليل إرهاق القرار** — كل خيار زائد يستهلك طاقة ذهنية. المنتج يقرر ما يهمّ اليوم، والمستخدم يبدأ فقط.
3. **الانتصارات الصغيرة تصنع الزخم** — أهداف صغيرة قابلة للإنجاز، لا أهداف ضخمة مرهبة.
4. **التعافي تقدّم** — الانقطاع متوقّع، والعودة تُحتفى بها. **لا يجوز أن يشعر المستخدم أنه "خسر كل شيء".**
5. **الأمان الشعوري** — يجب ألا يخاف المستخدم من فتح التطبيق بعد يوم سيء. المنتج يرحّب به كما هو.
6. **الفخر الهادئ** — النجاح يُحسّ شخصياً، لا يُعرض مسرحياً. لا ألعاب نارية.
7. **الختام بسلام** — كل يوم ينتهي بإغلاق واعٍ ومريح.

## 🚫 قائمة "لن نبني" (Never Build)

1. **لا Feed** يشبه TikTok/Instagram — المستخدم يأتي ليهدأ.
2. **لا ألعاب كثيرة** — قليلة جداً ولها هدف واضح.
3. **لا إشعارات مزعجة** — قليلة، ذكية، قابلة للتحكم.
4. **لا ادعاءات علاجية** — يبني عادات، وليس علاجاً طبياً.
5. **لا App Blocker في الإصدار الأول** — يزيد التعقيد.
6. **لا تكرار للميزات** — كل وظيفة لها مكان واحد فقط.
7. **لا مؤشرات بلا تفسير** — كل رقم يجيب: *لماذا؟* و *كيف أحسّنه؟*
8. **لا ميزات "ترند"** — كل ميزة تخدم البرنامج اليومي.
9. **لا تعقيد في التنقل** — أي وظيفة يومية خلال 3 نقرات كحد أقصى.
10. **لا محتوى يخالف الهوية** — لا موسيقى، لا صور نسائية، لا محتوى يثير الانتكاسة.
11. **لا توثيق متضخّم** — التوثيق يخدم البناء، لا يستبدله. **لا موسوعات، لا مجلدات 1000 صفحة.** المرجع كله ≤ 30 صفحة. لو التوثيق كبر عن كده، يبقى تسويف مش تخطيط.
12. **لا إعادة بناء من الصفر** — عندنا تطبيق شغّال + 196 اختبار + 12 مختبر. نطوّره تدريجياً.

## 🧱 مبادئ المنتج (العشرة)

المبادئ التي تحكم **كيف** نبني، لا **ماذا** نبني.

**1. اليومي يغلب المثالي**
تفويت يوم لا يغيّر شيئاً. العودة غداً تغيّر كل شيء.

**2. التقدّم قبل الأداء**
نحتفي بالاستمرارية، لا بالشدّة.

**3. الصفاء قبل الإنتاجية**
العقل الهادئ يؤدّي أفضل تلقائياً. نحسّن الصفاء أولاً.

**4. هدف واحد لكل جلسة**
يجب أن يعرف المستخدم دائماً **لماذا** فتح التطبيق.

**5. الأقل هو الأكثر**
كل ميزة تبرّر وجودها. **التعقيد عيب برمجي (bug).**

**6. الذكاء الاصطناعي يدعم — لا يستبدل**
صفا ترشد · المستخدم يقرر · الذكاء الاصطناعي يساعد · الإنسان ينمو.

**7. مساءلة لطيفة**
Brain Clean يُذكّر. **ولا يوبّخ أبداً.**

**8. كل يوم بداية جديدة**
الأمس يُعلِم اليوم — ولا يحدّده أبداً.

**9. المنتج يجب أن يصغر مع الوقت** ⭐
كل ما تحسّن المستخدم، احتاج Brain Clean **أقل** — لا أكثر.
**هذا عكس البرمجيات الإدمانية تماماً.**

**10. الحياة الحقيقية تكسب** ⭐
الجلسة المثالية تنتهي بـ: **اقفل التطبيق. عِش حياتك.**
**هذا هو النجاح.**

### مبادئ إضافية (من قراراتنا)

# الجزء الثاني: 📋 الوصف التقني الكامل (PROJECT REFERENCE)

## 📌 نظرة عامة

تطبيق Flutter عربي (RTL) يساعد المستخدم على بناء عادات صحية لتقليل إدمان الشاشات.

**التموضع الصادق:** أداة لدعم بناء عادات صحية — **ليس** علاجاً طبياً.

## 🔬 الأساس العلمي — الحقيقة كاملة

### ✅ ما يعمل (أدلة قوية) — نبني حوله

| التدخل | قوة الدليل | الأثر |
|---|---|---|
| **الراحة اليقظة / سكون** (Wakeful Rest) | متوسط–قوي | يحسّن الإبداع والذاكرة؛ يعيد شحن الانتباه |
| **اليقظة الذهنية / التأمل** | قوي | تأثير ثابت على الانتباه الانتقائي |
| **الرياضة / الحركة** | متوسط–قوي | تحسّن الانتباه المستمر وجودة النوم |
| **تقليل وقت الشاشة المدروس** | قوي (RCT) | حجب الإنترنت أسبوعين حسّن الانتباه والصحة النفسية |
| **تحسين النوم** | قوي | أساس التركيز |
| **الكتابة التعبيرية / دفتر القلق** | متوسط | تقنية CBT لتقليل القلق |
| **تمارين التنفس** | متوسط | تهدئة الجهاز العصبي |

### ❌ ما لا يعمل (يجب تصحيحه في التسويق)

| العنصر | الحقيقة |
|---|---|
| **ألعاب تدريب الدماغ** (N-Back, Stroop…) | تحسّن الأداء **في اللعبة فقط** — لا ينتقل للحياة. Lumosity دُفعت غرامة 2 مليون دولار (2016). |
| **"ديتوكس الدوبامين"** | مصطلح **غير علمي**. الصحيح: تقليل السلوك القهري. |
| **"مؤشر BCI"** | رقم **مخترع داخلياً**، ليس مقياساً طبياً — أداة تحفيز لا تشخيص. |

> **نقطة مضيئة:** الكلمات المتقاطعة تفوّقت على Lumosity في تجربة مباشرة — أفضل الأنشطة المعرفية علمياً.
