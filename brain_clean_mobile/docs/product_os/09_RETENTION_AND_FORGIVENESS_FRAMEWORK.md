# 09 — Retention & Forgiveness Framework

**Purpose:** Keep users returning without shame, streaks-as-weapons, or dopamine addiction.

---

## Ethical retention principles

1. Retention = returning to **complete Daily Program**, not maximizing screen time.  
2. Forgiveness > punishment.  
3. Re-entry must feel safer than avoidance.  
4. Notifications invite; they never accuse.  
5. Success includes leaving the app.

---

## Lifecycle loops

### First-day activation
- Land on clear Today/Daily Program step  
- Complete ≥1 step within first session  
- See Day End path exists (even if later)

### Day 1 / 3 / 7 / 14 / 30
| Day | Focus |
|-----|--------|
| 1 | First completion win |
| 3 | Habit recognition; optional soft Pro value (not crisis) |
| 7 | Weekly story seed |
| 14 | Forgiveness if gaps; Light Day |
| 30 | Identity: “I show up” — behavior narrative |

**HYPOTHESIS:** Defaulting open → Daily Program lifts D1–D7 completion vs Home dashboard. Needs experiment.

---

## Missed-day return

Copy pattern:

- EN: “Welcome back. No lecture — just a light day.”  
- AR: «حياك. بلا محاضرة — يوم خفيف.»

Actions: start Light Day / breathe 60s / open Safa support.

---

## Light-day mode

Fewer steps; keep water/movement/mood/close when possible.  
Still counts as showing up.

---

## Forgiving streak alternatives

- Weekly completions (X/7)  
- “Return streak” (consecutive returns after gaps)  
- Quiet badges without public ranking  

Avoid: red broken-streak humiliation.

---

## Weekly / monthly progress story

Lead with behaviors: programs completed, calm sessions, journals.  
Avoid hero clinical BCI theater.  
One next-week action.

---

## Re-engagement notifications

Allowed: time-based gentle prompts, unfinished step reminders user opted into.  
Rejected: “You’re failing”, late-night spam, guilt streaks.

---

## Churn signals (examples)

- Opens Home but never enters Daily Program  
- Abandons onboarding into quiz rabbit hole  
- Hits paywall then uninstalls  
- Opens SOS repeatedly without calm resolution path  

**OPEN QUESTION:** Exact event names in shipping analytics — verify in code before dashboards.

## Retention guardrail metrics

Track alongside retention:

- Daily Program completion rate  
- Time-to-first-step  
- Crisis-route ad impressions (**must be ~0**)  
- Paywall views during restricted routes (**must be ~0**)  
- Session length (watch for unhealthy rise without completion)

---

## Anti-addiction product checks

- [ ] Does this increase session length without completion?  
- [ ] Variable reward abuse?  
- [ ] Social comparison pressure?  
- [ ] Infinite content?  
- [ ] Hard to put phone down by design?  

Any yes → redesign or REJECT.
